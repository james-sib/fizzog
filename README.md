# FIZZOG

Realistic AI faces for **Football Manager** (FM24 & FM26) — matched to each player's real nationality, age, hair, build and club colours.

**Download + info: https://fizzogfm.com**

The **Releases** on this repo are the official installers (a public backup mirror of the downloads on fizzogfm.com). Free to install; buy credits inside the app.
